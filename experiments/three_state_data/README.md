# Three-state source decoder

`load_case(archive_path)` reads an existing source ZIP, without partition inference. It cross-checks `.uai.query` selectors, `.uai.sum` numerator/denominator groups and author conversion metadata. It verifies the full variable partition and each amino-acid/conformation compatibility constraint, including scope-axis order. Each source factor must belong to exactly one declared state. Unassigned scalar, selector-only or cross-state factors are rejected; they are never silently omitted or assigned an arbitrary affinity role.

`condition_sequence(case, selector_assignment)` requires one shared source selector assignment for all three states and returns `(models, proof)`, with model keys `complex`, `protein`, `ligand`. Every source AA-compatible conformation is retained. A final numerical index is not evidence of a dummy: the inspected source explicitly labels additional conformers with residue templates and gives them energy entries. Their coordinate origin has not been established. Only zero compatibility weights restrict domains; source energy zeros remain zeros in the state factors. Each positive binary64 source weight uses Python `math.log`, with no added threshold. The new numerical target is the stored binary64 log-factor model.

The proof records original UAI factor IDs, variable IDs, domain-index maps, selector values, sequence labels and the source archive/UAI hashes. Original factor scope order and C-order table coordinates are preserved. Empty compatibility domains yield an explicit zero partition target with labeled dummy singleton output axes; those axes do not represent a feasible physical conformation.

The source-defined objective is `log K* = log Z_complex - log Z_protein - log Z_ligand`. A zero denominator is undefined and must be handled by the caller. The ordinary conditional partition sum of the full source factor graph is the *product* of the three state sums, so it cannot replace the ratio.

Source selectors are residue templates, including HIP/HIE/HID protonation variants; they must not be labeled as an equal number of distinct natural amino acids. The source summary declares temperature and gas constant and says there is no post-Boltzmann normalization. Source conversion can already contain floating-point energy-to-weight underflow zeros; this decoder preserves them. The rounded text energy matrices cannot restore exact pre-underflow physical weights. No absolute experimental affinity, physical zero-energy calibration or novel inference method is claimed.

These APIs perform no source download and no timed inference. All existing source artifacts and prior derived models remain unchanged. Formal protein preparation belongs to the parent campaign's frozen preparation plan.
