# Campaign 005: physical-input readiness and finite-energy sensitivity

Status: prospective grader protocol. Work classification: exploratory `poc`.

The question is whether the next study can test an ensemble affinity prediction against experimental observations, and, separately, whether the previous ranking depends on source underflow. Repeating numerical agreement or increasing solver throughput cannot pass the biological gate.

This protocol is frozen before new campaign-005 predictions or finite-energy scores. Candidate discovery, original-file inventory, metadata mapping and source-code inspection are preparation, not predictions. Record all exposure. The prior pilot's case, full 21-template panel and ranking are already known; any follow-up on it is a declared follow-up, not a blind replication. Never overwrite the prior campaigns, this freeze or later execution manifests; amendments get new named files.

## 1. Candidate readiness gate

Inventory every considered candidate, URLs/retrieval times, source versions/licenses, downloaded byte hashes, available artifacts, failures and rejection reasons. Downloading coordinates alone does not establish readiness. A bounded search can conclude that no tested candidate is ready; it cannot conclude universal unavailability.

Before an experimental prediction study can be activated, the preparation manifest must identify:

1. A public primary paper and exact assay table, raw measurement or supplement. Each unique predicted sequence maps to one molecular system and one measurement with an explicit unit and observation type (Kd, Ka, IC50, enrichment or other). Retain replicates, errors, censoring, temperature, pH, buffers and assay differences when supplied; missing fields are explicit. IC50/enrichment are not silently treated as Kd. Do not average incompatible assays.
2. Exact identities, numbering, chain/assembly, ligands/cofactors, termini, mutations and protonation templates for bound complex and both free partners. Structures and prepared conformer sets/energy tables need reproducible provenance. A nominal PDB identifier is insufficient when the scripts expect a modified structure.
3. Either complete matched three-state energy/conformer inputs or a runnable, fixed molecular preparation procedure with force field, solvent, reference energies, temperature, all scalar offsets and multiplicities. Full precision is preferred; any lossy serialization or approximation is identified and bounded where possible. Preparation costs count. A regenerated model is a new target, not automatically the released UAI target.
4. A defined score orientation and comparison. For a matched dimensionless model, `logK = logZ_C - logZ_P - logZ_L`; relative experimental affinity is `-ln(Kd_variant/Kd_reference)`. A physical absolute Ka/Kd additionally needs standard-state, translational/rotational and other omitted conventions. Missing absolute calibration need not preclude a clearly labeled within-assay rank test, but must preclude calibrated molar predictions.
5. A fixed sequence panel, model parameters and inclusion rules selected without examining new prediction outcomes or their correlations. All labeled variants with compatible inputs under the declared state cap are included, with no arbitrary variant-count truncation. Use at least six unique compatible variants for an exploratory biological rank test; fewer produce feasibility observations only. Repeats and multiple protonation templates are not independent biological variants. Preserve a complete all-candidate denominator when Cartesian-size or input-completeness rules exclude cases.

The named first candidate is Lowegard et al. (2020), DOI `10.1371/journal.pcbi.1007447`, Harvard Dataverse DOI `10.7910/DVN/VHIRNM`, archive `rasDesigns.zip`. Its original `retrospective/bbks/ks1.cfs` through `ks34.cfs`, matching structure and binary rigid matrices are the prospective primary input family. This nomination follows inspection of source availability, README/configuration metadata and the primary paper, before reading archived numerical prediction rows or calculating new scores. The independent metadata inventory finds all 34 core configurations and all 204 declared rigid/minimized state matrices present. Presence is not yet a conformation-map or energy-semantics pass.

If this candidate fails readiness, other ready candidates are ordered by complete released energy/conformer inputs; completely scripted molecular preparation; then canonical DOI and dataset identifier. This is an availability rule, not a prediction-quality rule. A candidate chosen by another rule needs a prospective amendment before scores.

The existing armadillo-label collection is not ready merely because it has 63 labels: the prior audit found missing prepared structure/conformer/energy inputs. It can pass only if those inputs are newly obtained or a complete preparation workflow is explicitly built and frozen. Parent/source workers' claims are evidence to audit, not automatic passes.

## 2. Biological study activation and evaluation

No new biological predictions before a separate immutable activation record binds the chosen candidate, exact variant/assay mapping, code/environment, preparation, objective, comparator, tolerances, budgets and all-attempt schedule. The grader checks readiness first. A no-go is a valid useful outcome when an essential input is absent; do not rename a sensitivity study as biological validation.

For a ready panel, the primary exploratory endpoint is within-assay Spearman association between the ensemble score and `-ln(Kd)` (or another explicitly justified observation). Report N, all points, missing/censored outcomes, ties and a two-sided exact permutation p-value for N<=9 or 10,000 seeded permutations otherwise. Report a seeded variant-level bootstrap 95% interval with 10,000 resamples, including undefined constant resamples; a small correlated panel does not establish generalization. Do not pool assays or proteins without a frozen stratified endpoint. For censoring, report compatible order constraints or a frozen censor-aware method; do not substitute the detection limit as an exact value. Missing measurement errors cannot become zero error.

The minimum meaningful comparator is the same molecular model's single lowest-energy-conformation binding score, with the same sequence coverage and normalization conventions. A constant/no-mutation baseline is also reported. A native published method is an additional comparator if runnable on compatible inputs; unavailable native software is not a local solver win. Compare ensemble versus minimum-energy prediction on the same complete variants. Report numerical uncertainty and assay uncertainty separately. No parameter fitting on the evaluation labels; any calibration/training requires a predeclared held-out split and separate endpoint. A positive correlation alone is not proof that ensemble counting improves prediction. With fewer than 20 independent variants, describe comparative results as a pilot rather than a reliable winner.

When source designs have different local flexible shells or conformation spaces, the primary prediction is each variant's score change from its own matched wild type in that exact design. Do not rank raw scores from different spaces. The GMEC and archived-method comparators receive the same matched-WT normalization. A repeated variant in different designs is one biological observation: choose its eligible configuration with the smallest sum of WT-plus-mutant Cartesian assignment counts over the three states, then numeric configuration identifier to break ties. Match experimental ratios to their corresponding WT observation in the same assay. Rigid-matrix ensemble sums are a distinctly named discrete model; sums of minimized pairwise lower-bound matrix entries are not silently treated as energies of fully minimized conformations. Archived continuous K* results are a different-model comparator whose selection, bounds and provenance must be retained.

For the named KRas candidate, inventory all sequences declared by all 34 core configurations. A full sequence, one matched WT and all three states must map exactly to source template/conformer order and the experimental variant identity. Verify WT against the prepared structure and source configuration; do not guess from a sequence's score. A sequence/configuration pair is eligible only when each WT and mutant state has at most 1,000,000 Cartesian assignments and complete rigid input. Preserve every ineligible pair and its reason. Choose duplicate variants by the preceding count rule. Order the resulting unique-variant records by total WT-plus-mutant Cartesian count, then canonical full variant identity, then numeric configuration identifier. Admit that ordered prefix whose cumulative count is at most 50,000,000 assignments, counting the declared WT and variant slots even if later exact cache reuse saves work. Do not replace excluded records after seeing a result. The final preparation manifest binds the exact counts, slots, panel and assay mapping before scoring. This is a size-selected pilot and must report the whole initial denominator.

The primary biological endpoint is separate within each original assay source/observation type. The published retrospective table combines percent-binding observations and dissociation measurements; a pooled comparison may be shown only as contextual secondary analysis with these distinctions visible. The single-concentration BLI off-rate/response screen is not a titration Kd. Prespecify treatment of source score bounds: apply WT normalization with opposite endpoints for subtraction, preserve overlap as uncertainty, and never silently select a favorable bound. Archived outputs are reported as previously published predictions, not fresh independent validation or an exact rigid-target reference.

For Ras studies, verify the actual assay's Ras isoform/species, GDP/GTP or nucleotide-analogue state, engineered background and c-Raf construct from the original source, not only the 2020 table caption or a paper title. Also verify these against the prepared model. A homologous protein or different nucleotide/background permits a separately labeled model-transfer comparison, not the exact matched-assay endpoint. If fewer than six compatible direct observations remain, report the smaller case study and the failed size/readiness gate without presenting a pooled transfer correlation as direct validation.

The core `bbks/ks1` through `ks34` inputs stay canonical. `.null` and `ewaks` matrix/configuration families are inventoried separately and cannot silently fill a missing primary state. Any fallback requires a prospective amendment plus complete configuration, conformer/order, energy/reference and state equivalence checks. Archived BBK*/EWAK* outputs are matched to exact model definitions before comparison; incompatible or missing outputs stay missing. Decoding audits and synthetic checks precede enumeration, and all exposure to native output numbers is recorded.

Independently verify at least one complete small three-state target by raw-source enumeration or another implementation that does not import experiment scoring code. Check all mapping, sign, scalar-offset and zero-support conventions for every evaluated target. Numerical uncertainty must be substantially below the smallest claimed resolved score gap. Record partial results and timeouts; do not correlate only successful favorable variants without reporting the frozen denominator.

## 3. Separate, permitted numerical bridge

If physical inputs are not ready, one explicitly named finite-energy sensitivity follow-up is permitted on the already selected campaign-004 case and all 21 templates at F338. This answers whether the encoded ranking is robust to restoring finite energy contributions. It is not biological validation, does not recover coordinates, and cannot establish experimental accuracy. It must not replace the readiness search or suppress its no-go.

Before any new finite-energy score, freeze a bridge activation manifest binding all source archives, panel and mapping, energy text precision, Boltzmann constants, code/environment, numeric procedure, sensitivity scenarios, caps and expected 63 state slots. Do not reselect a case or drop templates because a restoration is difficult or unfavorable. Keep the known source-encoded ranking as a declared comparator.

Required bridge targets are: (a) the existing released-weight target, audited against its sealed prior references; (b) a distinctly named rounded-energy-center model using finite `-E/(RT)` directly in log space for every energy factor, retaining true structural/selector constraints; and (c) conservative energy-rounding envelopes under an explicitly declared precision/rounding assumption. Never turn an underflowed finite energy into an exact hard constraint in targets (b/c). Conversely, do not restore genuine structural impossibility without source evidence. All energy factors, scalars, conformers and multiplicities must map; unexplained zeros, infinities or unmatched terms trigger a failed gate rather than a guessed repair.

If rounding-to-nearest at the declared textual precision is not established, intervals based on half a printed unit are conditional scenarios, not certificates for the original unrounded energies. Also evaluate a full printed-unit perturbation scenario or explain its omission prospectively. Shared source factors stay shared; an independent worst-case factor box may be conservative but cannot be called a posterior probability. A sufficient conservative state bound is the sum of allowed per-factor energy deviations divided by `RT`; propagate ratio signs correctly. Tighter positive-factor endpoint partition bounds are acceptable. Any solver/exponential truncation needs a separately proved tail bound; binary64 underflow alone is not permission to discard restored weight.

Report all 63 original/restored state log partitions, all 21 score centers and envelopes, changes from the released model, support/Cartesian counts, top-1/3/5 membership and all 210 pairwise order statuses: preserved, reversed or unresolved by the envelope. Envelopes overlapping zero difference must not be forced into an order. State whether the baseline remains best under each stated scenario. Report upper bounds even when observed differences round to zero. A stable rank is useful robustness evidence for the declared model; an unstable or unresolved rank is also useful. Neither is a measured affinity result.

The grader independently parses original sources, checks every state/factor/energy correspondence, recomputes the restored targets and bounds, and verifies a separate high-precision numerical reference without importing experiment code. Independent 60/90 decimal-digit agreement with an explicit numerical allowance is evidence, not automatically a rigorous outward-rounded interval. If claimed intervals are certificates, arithmetic/rounding and every tail bound must support that claim. Reuse of sealed earlier parsers or helpers is disclosed and hashed.

## 4. Resources and bookkeeping

Local CPU only; no paid/cloud compute, remote publication or author contact. No installation or compilation is implied by a source inventory; any new dependencies are isolated and locked. Default activation ceiling: two CPU workers, 2 GiB observed process-tree RSS per worker, 30 minutes total preparation and 10 minutes scoring/audit per selected study; 120 seconds per prediction state and 20 million explicit assignments per state. Record serial/parallel accounting, all stages, wall/CPU and peak RSS. These are ceilings, not a reason to use the full allocation. If the chosen target cannot fit, record not run/timeout and the precise missing resource. Changing a ceiling requires a prospective amendment, never an invisible retry.

For the numerical bridge, prefer the smaller ceiling of one CPU worker, 512 MiB observed RSS, 300 seconds total experiment/reference computation, 60 seconds per state and one million explicit assignments per state. Static source inventory is charged separately and reported. A complete slot ledger distinguishes direct solves, traced identical-target reuse, references, skipped states and failures. Cache preparation and validation count; a cache hit is not a new independent state evaluation. RSS sampling/high-water cannot prove an instantaneous hard limit; record actual monitoring scope and timestamps.

Freeze source/code/environment identities before execution; capture observed runtime versions at startup. Preserve stdout/stderr, initial development failures and every scheduled attempt. Synthetic checks must test sign/offset/zero/interval branches meaningfully; do not add tests merely asserting configuration. No new measured run is valid until relevant local checks pass. No performance winner is sought in this phase; if timing claims are later introduced, add an explicit counterbalanced schedule before measurements.

## 5. Verdict vocabulary

- **Ready / not ready:** bounded molecular-input and measurement audit, with exact missing artifacts.
- **Biological pilot pass / inconclusive / fail:** only after the separate activated matched-assay study; numerical correctness is necessary but insufficient.
- **Finite-energy robustness established conditionally / unresolved / contradicted:** only for the specified model and rounding assumptions.
- **General solver or biological winner:** not supported by this small follow-up.

The final grader report separates these gates, preserves negative results and states exactly what useful conclusion was reached. Candidate parent plots and claims are independently checked before endorsement.
