# Premeasurement execution details and cohort audit

Recorded on 2026-11-11 after metadata inspection and before any external selected
instance counts or timing. The scientific query, cohort rule and continuation
gate in the prospective protocol are unchanged.

The certified method stops starting new search batches once eight seconds have
elapsed from its worker's start, including input parsing, translation and producer
preparation. It then generates and checks its current certificates, with a
two-second native-checker subprocess limit. The enclosing supervisor retains a
ten-second hard query limit and must terminate the worker's whole process group.
An overrun is a timeout, not an unchecked solved decision. Ganak receives a
9.8-second shared child deadline for both counts beneath the same outer limit.
These source-level budgets are fixed before reference answers or performance are
observed; they are not tuned using outcomes.

Use supervisor wall time for the primary comparison. It includes cold Python
worker startup/imports and final result/certificate serialization. The worker's
own `worker_seconds` and stage timings are diagnostics, not substitutes for the
complete invocation time.
